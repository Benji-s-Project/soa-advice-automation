## 1. Purpose and Scope

1.1  The Client engages the Provider to design, build, and deliver an AI-powered Statement of Advice (SOA) automation platform that generates compliance-ready SOA documents from voice notes or call transcripts.

1.2  The platform will integrate with Quote Monster (for premium comparisons, QPR ratings, product research, and SOA report generation) and Trail CRM (for client profile data retrieval), and will use AI to process adviser voice input or call transcripts into structured SOA documents.

1.3  The core deliverables include:

- Voice note and/or call transcript input processing
- AI extraction of adviser recommendations, reasoning, and product selections
- Quote Monster API integration (quote creation, premium comparisons, research reports, SOA generation)
- Trail CRM API integration for client data retrieval (subject to Trail API availability)
- Branded SOA PDF generation matching the Client's existing format
- Web-based review dashboard for the Client to review, edit, and send SOAs
- Email delivery of completed SOAs to clients

1.4  The platform is built for use by the Client's licensed financial advisers only and is not intended for direct-to-consumer use.
